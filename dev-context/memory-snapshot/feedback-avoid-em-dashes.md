The user asked me to avoid overusing "—" (em-dashes) in my wording. Prompted by the VTree
walkthrough orientation paragraph, which had two em-dashes in one sentence ("VTree answers one
query — … — over billions…"); they had it rewritten to a plain declarative sentence.

**Why:** heavy em-dash use reads as fussy / AI-generated and hurts readability.

**How to apply:** in artifacts, docs, commit messages, and chat prose, prefer periods, commas, or
colons over em-dashes. Reserve "—" for the occasional genuine aside; don't stack two in a sentence
or use them as a default connector. Applies to authored artifact copy too (e.g. [[artifact-sql-waf-reset]]
VTree pages) — favor short sentences over dash-joined clauses.
